The library page (`src/routes/+page.svelte`) has a commented-out visual debug panel for tracing data loading on mobile (where DevTools are unavailable). To enable: uncomment the `diagLogs`/`showDiag`/`diag` variables in the script block, the `diag()` calls in `onMount`/`refresh`/`loadAllBookProgress`, and the DBG button template at the bottom. The panel appears as a fixed overlay with a green-on-black `<pre>` block.
