Проблема: картинка вылезает за пределы экрана. Хотим: фулскрин + зум пальцами.

План

  1. CSS-фикс: добавить max-height + overflow, чтобы картинка не вылезала
  2. Клик по картинке → фулскрин с тёмным фоном
  3. Pinch-to-zoom пальцами для увеличения
  4. Тап → закрыть

Как реализовать зум?

1

Нативные touch-события

TouchEvent + CSS transform. Без библиотек, легковесно. Контролируем pinch, pan, double-tap сами.

  • Нет зависимостей
  • Полный контроль
  • Ручная обработка жестов
2

pinch-zoom npm пакет

Готовая библиотека вроде @panzoom/panzoom или pinch-zoom-js.

  • Из коробки
  • Меньше кода
  • +1 зависимость
  • API оверхед
