Поток данных

📄 HTML контент главы (уже с data-uri картинками)
↓ image-transformer.ts — добавляет data-attr изображениям
↓ {@html content} в ReaderContent
↓
┌─ Клик на картинку ──────────────┐
│ ReaderContent ловит событие │
│ → Открывает ImageFullscreen │
└─────────────────────────────────┘
┌─ ImageFullscreen ───────────────┐
│ Тёмный фон (position:fixed) │
│ Картинка по центру │
│ Pinch → scale + translate │
│ Тап → закрыть │
└─────────────────────────────────┘

Компоненты

🆕 ImageTransformer (модуль)

Обрабатывает HTML строку: находит <img> и добавляет data-image="true"

🆕 ImageFullscreen.svelte

Фулскрин оверлей. Пропсы: src (data-uri), onClose. Touch-обработка внутри.

✏️ ReaderContent.svelte

CSS max-height для img + обработчик клика по делегированию + рендерит ImageFullscreen

PDF и EPUB?

Фикс касается только EPUB (HTML-контент). В PDF изображения обрабатываются иначе — оставляем как есть.
