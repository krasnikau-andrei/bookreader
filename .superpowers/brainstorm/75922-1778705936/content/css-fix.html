CSS-фикс переполнения

max-width: 100% считает ширину от колонки (100vw - 2rem), игнорируя padding на > *

Проблема
🖼️ Картинка на всю ширину колонки, игнорируя паддинг
читаемая область 💥 картинка вылезает

Фикс

.content :global(> *) {
    padding: 0 var(--reader-gap-sides);
    margin: 0;
    overflow-x: hidden;  /* ← добавить */
}

overflow-x: hidden — режет только горизонтальное переполнение, вертикаль не трогает.
